# Fonts and icons embedded in the SVGs

## Fonts (SIL Open Font License 1.1) - embedded as base64 WOFF2, subset to the glyphs each SVG uses
- Playfair Display 400, 400 italic, 700 - Copyright 2017 The Playfair Display Project Authors
  (https://github.com/clauseggers/Playfair-Display). License: OFL-PlayfairDisplay.txt
- JetBrains Mono 400, 700 - Copyright 2020 The JetBrains Mono Project Authors
  (https://github.com/JetBrains/JetBrainsMono). License: OFL-JetBrainsMono.txt
- Obtained from the @fontsource/playfair-display and @fontsource/jetbrains-mono npm packages (v5.3.0, OFL-1.1),
  subset with fontTools. No glyph outlines were altered.

## Icons
- Brand marks come from Simple Icons (CC0 1.0 for the icon data; the marks themselves remain trademarks of their
  owners and are used here only to point at the named product). License: SimpleIcons-CC0.md
- Simple Icons v16.35.0: Python, TypeScript, Rust, React, Tailwind CSS, Node.js, FastAPI, Tauri, Ollama, OpenCV,
  Hugging Face, SQLite, PostgreSQL, Git, GitHub, Vercel, Supabase, MongoDB, Blender, Google Gemini.
- Simple Icons v13.21.0 (last release that still contains them): LinkedIn, Amazon Web Services.
  They were removed from later releases, and the brands' own press kits could not be reached from the build sandbox,
  so these two are Simple Icons' renderings of the marks, not files taken from the brands' own sites.
- No Simple Icons mark exists for RAG or FAISS: those two use plain generic line glyphs drawn for this project
  (a document with a magnifier, and a vector-neighbour scatter). They are labelled, and are not brand marks.
- The envelope (email) and globe (portfolio) glyphs are generic line drawings made for this project.
- Colour choice: every icon is drawn in platinum #EEF2F9. No brand colours are used anywhere.
